Storibox Photo Extractor

Paste a saved Storibox album page's HTML (or upload the .html file) to pull out the real photo/video URLs, skipping the watermark overlay. Pasting a bare URL will try fetching it directly, but most sites block that from a browser — if it fails, use "View Page Source" on the album page instead. Runs entirely in your browser — nothing is uploaded anywhere. Source on GitHub, or use the Node CLI for fetching a live URL directly.
